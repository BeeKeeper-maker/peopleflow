# PeopleFlow Role UAT Workflow

Use this to verify the system like a buying company would use it.

## Test roles
- admin/super admin
- HR admin
- manager
- employee

## Workflows
1. Login/logout for each role.
2. Employee create/edit/view/profile.
3. Department/designation/branch/shift setup where available.
4. Attendance check-in/today.
5. Leave type + leave application + manager/HR approval/rejection.
6. Notifications read/list.
7. Upload and secure download.
8. Export employee data.
9. Payroll/sample salary workflow if available.
10. Worker/queue event processing.
11. Tenant isolation: tenant A cannot access tenant B records.

Report pass/fail with evidence and screenshots/logs where possible.
